# RoboCasa Demo Media

These files are selected documentation artifacts, not installed datasets.

| File | Content |
| --- | --- |
| `retriever-robocasa-web-console.jpg` | Retriever console with a `PrepareCoffee` replay rendered by mjviser. |
| `retriever-robocasa-scene-launcher.jpg` | Task catalog and embedded `PrepareCoffee` viewer. |
| `retriever-robocasa-rerun.jpg` | Rerun telemetry and camera view for `TurnOnMicrowave`. |
| `turn-on-microwave-replay.jpg` | Poster frame for the replay clip. |
| `turn-on-microwave-replay.mp4` | Short `TurnOnMicrowave` demonstration replay. |

The simulator frames were rendered from
[RoboCasa `921c9a5`](https://github.com/robocasa/robocasa/tree/921c9a5736a8d0ea5589657898aadcfa55a6a195).

authors. The captures add GoldenRetriever UI, telemetry, cropping, resizing,
and video encoding. No downloaded dataset or kitchen asset source files are
included here.
