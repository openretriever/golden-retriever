<p class="kicker">Applied payload layer</p>

Core Retriever teaches Flow, Pipeline, clocks, sync policies, execution, IR, replay, and Hub loading. Golden adds the robot-facing vocabulary on top of that runtime: world state, belief, skills, plans, trajectories, stamped spatial values, event buffers, dataset records, and export profiles.

## First Runnable Checks

```bash
pixi run demo-robotics-typing-catalog
pixi run demo-robotics-typing-contract
pixi run demo-robotics-typing-boundary
```

Expected result: terminal output that constructs stamped spatial payloads, checks composite I/O access rules, and preserves frame, time, and source metadata across a perception-to-control boundary.

## What Golden Provides

| Area | Golden provides | Core Retriever provides |
| --- | --- | --- |
| Robot payload vocabulary | `WorldState`, `BeliefGraph`, `Skill`, `Plan`, `Trajectory`, status, and stamped robotics examples. | Runtime, clocks, Flow/Pipeline execution, IR, replay, and registry mechanics. |
| Composition contracts | Public examples for composite I/O, qualified fields, and validation boundaries. | The composition/runtime semantics used by those examples. |
| Event/data profiles | `Event`, `EventBuffer`, event-time joins, manifests, and LeRobot bridge examples. | Runtime event-buffer mechanics and scheduler behavior. |
| Hub readiness | Pack boundary, export catalog, smoke demos, and promotion guidance. | Hub loader and registry integration. |
