<p class="kicker">Hub-loadable boundary</p>

The Golden pack should stay import-safe: loading these exports must not require a camera, simulator, model, robot, network service, or local source-tree knowledge. This page mirrors the current `[tool.retriever.module.exports]` manifest.

<div class="inline-command">
  <strong>Verify the manifest boundary</strong>
  <pre><code>pixi run demo-golden-hub-pack</code></pre>
  <p>Expected result: exports load, representative payloads instantiate, and the Arrow conversion helpers round-trip a lightweight action payload.</p>
</div>

## Export Groups

<div class="choice-grid">
  <div class="choice-card"><span>Scene</span><strong>World and belief</strong><p><code>WorldState</code>, <code>RobotState</code>, and <code>BeliefGraph</code> cover current state and remembered state.</p></div>
  <div class="choice-card"><span>Task</span><strong>Goal, skill, plan</strong><p><code>TaskGoal</code>, <code>Skill</code>, <code>Plan</code>, and <code>StructuredPlan</code> cover planner-facing intent and action structure.</p></div>
  <div class="choice-card"><span>Control</span><strong>Trajectory and status</strong><p><code>Trajectory</code> and <code>ExecutionStatus</code> cover motion handoff and progress reporting.</p></div>
  <div class="choice-card"><span>Interop</span><strong>Core helpers</strong><p><code>Action</code>, <code>Command</code>, <code>Status</code>, <code>convert_to_arrow</code>, and <code>convert_from_arrow</code> cover lightweight exchange and dataset paths.</p></div>
</div>

## Use Directly Or Through Hub

```python
from retriever import hub
from retriever_typing.robotics_types import WorldState

WorldStateFromHub = hub.use("openretriever/golden-retriever:WorldState")
assert WorldStateFromHub.__name__ == WorldState.__name__
```

<div class="boundary-note">
<strong>Promotion rule:</strong> a Golden export is public only when this catalog, the manifest, and <code>demo-golden-hub-pack</code> agree. If an export needs optional simulator/model/camera dependencies, keep it source-only until it has a lightweight boundary.
</div>
