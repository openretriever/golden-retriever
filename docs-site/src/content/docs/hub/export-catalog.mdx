The current Golden pack focuses on robot-facing payloads and lightweight conversion helpers. It should remain import-safe: no camera, simulator, model, robot, or network dependency should be required to load these exports.

| `BeliefGraph` | Robot task payload | Memory and grounding. |
| `Skill` | Robot task payload | Planner to controller handoff. |
| `Plan` / `StructuredPlan` | Robot task payload | Language/task planning. |
| `Trajectory` | Motion payload | Motion planner/controller examples. |
| `ExecutionStatus` | Status payload | Monitor and controller outputs. |

```bash
pixi run demo-golden-hub-pack
```
