Golden is the proving ground for reusable Retriever Hub packs. A source example becomes a pack candidate only when the public boundary is stable enough for another project to load it without understanding the source tree.

```python
from retriever import hub

WorldState = hub.use("openretriever/golden-retriever:WorldState")
```

## Pack Rules

| Rule | Why it matters |
| --- | --- |
| Export through the manifest | Keeps the public surface explicit. |
| Keep imports lightweight | Loading a type pack should not import robot, simulator, model, or camera dependencies. |
| Smoke every export | `demo-golden-hub-pack` should prove the boundary. |
| Document expected output | Users need to know what success looks like. |
