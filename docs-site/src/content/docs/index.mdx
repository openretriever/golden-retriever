## Quick Start

Start here after the core Retriever visual quickstart works. Golden is a separate source checkout:

```bash
git clone https://github.com/openretriever/golden-retriever.git
cd golden-retriever
pixi install
pixi run demo-golden-hub-pack
```

<details class="explain-details">
  <summary>What does this do?</summary>
  <div>
    <p>The command loads the Golden Hub exports through Retriever Hub, constructs representative payloads, and round-trips a command through Arrow helpers. It requires no robot, camera, simulator, model, network service, or GUI.</p>
  </div>
</details>

## How The Retriever Surfaces Fit

| Surface | Owns | Start here when... |
| --- | --- | --- |
| Core Retriever | Flow, Pipeline, clocks, sync policies, IR, execution, replay, graph rendering, and Hub loading mechanics. | You need to understand or debug the runtime model. |
| Golden Retriever | Applied robot examples, robot payload references, simulator lanes, visualization demos, and Hub pack candidates. | You want runnable robot-facing examples after the core quickstart. |
| Retriever Hub | The packaging boundary for stable Flows, robot payload references, and conversion helpers. | You want reuse without depending on source-tree layout. |

## Common Patterns

| Need | Start with | Avoid first |
| --- | --- | --- |
| Safe Golden smoke | `pixi run demo-golden-hub-pack` | Camera, simulator, model, or network setup. |
| Example behavior | `pixi run -e golden-local demo-perception-detection-flow` | Optional model-backed lanes. |
| Simulator integration | `pixi run demo-robosuite-mock` | Real robosuite before the mock trace works. |
| Graph visualization | `pixi run demo-pipeline-html-viz` | Screenshots or stale generated HTML. |
| Robot payload reuse | `pixi run demo-robotics-typing-catalog` | Ad hoc dict payloads or source-only imports. |
