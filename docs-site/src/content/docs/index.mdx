<div class="boundary-note">
<strong>Golden is not a second runtime.</strong> Install and learn Retriever once. The Python import package is <code>retriever</code>; Golden provides applied examples and pack candidates on top of that runtime. If you need Flow, Pipeline, clocks, sync, or replay semantics, use the core runtime docs; otherwise stay on this Golden path.

## For AI Agents And Fast Audits

Start from [`/llms.txt`](/llms.txt), then run the smoke sequence before editing examples:

```bash
pixi run demo-golden-hub-pack
pixi run -e golden-local demo-perception-detection-flow
pixi run demo-pipeline-html-viz
pixi run public-surface-check
```

Treat these as public-contract checks: if one fails, fix the example, task, or docs together instead of adding another undocumented launch path.

## What Belongs Here

| Surface | Lives in Golden? | Why |
| --- | --- | --- |
| Flow, Pipeline, clocks, sync, IR, replay, execution | No | These are core runtime semantics and stay in the core Retriever docs. |
| Robot-facing payload packs | Yes | Golden defines applied `WorldState`, `BeliefGraph`, `Plan`, `Trajectory`, command/status, and conversion examples. |
| Perception, memory, language, composition examples | Yes | These are the maintained ladder after the core quickstart. |
| Camera, simulator, visualization, notebook lanes | Yes, with dependency labels | Optional lanes should not block the first run. |
| Hub-pack candidates | Yes | Golden is the proving ground before examples become reusable Hub packs. |
